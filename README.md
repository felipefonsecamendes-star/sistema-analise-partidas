# Sistema de Análise de Partidas (GameMetrics)
TCC - Técnico em Análise e Desenvolvimento de Sistemas.

## Como rodar
1. `npm install`
2. Copie `.env.example` para `.env` e preencha.
3. No MySQL: execute `database/schema.sql` e depois `database/seed.sql`.
4. `npm start` e abra http://localhost:3000
